# identify_secret_key

# 姓名 - 身份密钥管理工具

## 一、项目概述

这是一款面向 Excel 文件的**姓名 - 身份密钥批量生成与管理工具**，基于 Python 开发。本工具采用工程化设计思路，实现了密钥的安全生成、批量重置、历史追溯及规范化日志记录等核心能力。工具全程提供交互式操作界面，无需编写代码即可完成所有核心操作，完美适配 Windows、macOS 和 Linux 全平台。

------

## 二、核心特性

- **安全密钥生成**：基于 Python 官方 `secrets` 安全库生成高随机性密钥，比 `random` 库更适合身份标识场景，支持自定义长度和字符集。
- **灵活密钥重置**：支持全量一键重置、指定姓名精准重置两种模式；可自主选择是否保留历史密钥，方便变更追溯。
- **规范化日志系统**：自动记录全流程操作日志、错误详情和运行时间。日志文件超过 5MB 自动分割，最多保留 3 个历史日志，避免磁盘占用。
- **配置与代码完全分离**：所有可调整参数全部集中在 `config.py` 文件中，无需修改核心业务代码，即可快速适配不同使用场景。
- **数据容错校验**：自动过滤 Excel 中空姓名行，校验列名有效性，避免因无效数据和操作失误导致的报错。

## 五、核心配置说明

所有可调整参数均在 `config.py` 文件中定义，无需修改核心代码。关键配置项说明如下：

- **`INPUT_EXCEL_FILENAME`**：输入 Excel 的文件名，需提前放入 `input` 目录中，默认值 `"姓名列表.xlsx"`。
- **`OUTPUT_EXCEL_FILENAME`**：输出结果 Excel 的文件名，自动生成在 `output` 目录中，默认值 `"姓名_身份密钥.xlsx"`。
- **`NAME_COLUMN`**：Excel 中姓名列的列名，可修改为 "员工姓名"、"用户名" 等实际列名，默认值 `"姓名"`。
- **`KEY_COLUMN`**：生成的密钥对应的列名，默认值 `"身份密钥"`。
- **`HISTORY_KEY_COLUMN`**：重置密钥时，用于保存历史密钥的列名，默认值 `"历史密钥"`。
- **`KEY_LENGTH`**：生成的密钥长度，建议设置范围 8~32 位，默认值 `16`。
- **`KEY_CHARSET`**：密钥字符集配置。
  - `ascii_letters`（仅大小写字母）
  - `digits`（仅数字）
  - `ascii_letters+digits`（字母 + 数字，**默认值**）
  - `ascii_letters+digits+punctuation`（字母 + 数字 + 特殊字符）
- **`DEFAULT_KEEP_HISTORY`**：重置密钥时，是否默认保留历史密钥，可选 `True` / `False`，默认值 `True`。
- **`LOG_LEVEL`**：日志输出级别，可选 `DEBUG` / `INFO` / `WARNING` / `ERROR` / `CRITICAL`，默认值 `"INFO"`。
- **`LOG_MAX_BYTES`**：单个日志文件的最大大小，默认 5MB (即 5242880 字节)，超过后自动分割，默认值 `5242880`。
- **`LOG_BACKUP_COUNT`**：最多保留的历史日志文件数量，默认值 `3`。

## 六、详细使用步骤

### 1. 准备输入文件

将包含姓名列的 Excel 文件（如 `姓名列表.xlsx`），复制到项目根目录下的 `input` 文件夹中。

### 2. 调整配置（可选）

根据实际需求，使用文本编辑器打开 `config.py` 修改配置项。常见修改示例：

- 若 Excel 中姓名列的列名是 "员工姓名"：修改 `NAME_COLUMN = "员工姓名"`
- 若需要生成 8 位纯数字密钥：修改 `KEY_LENGTH = 8`、`KEY_CHARSET = "digits"`
- 若重置密钥时不需要保留历史：修改 `DEFAULT_KEEP_HISTORY = False`

### 3. 运行程序

打开系统终端 / 命令行，切换到项目的根目录，执行以下命令启动程序：

Bash

```
python key_generator.py
```

### 4. 交互式操作

程序启动后，会显示如下操作菜单，按照提示输入对应编号即可完成操作：

```
============================================================
🎯 姓名 - 身份密钥管理工具（工程化版）
============================================================
请选择操作：
1. 生成身份密钥（首次处理）
2. 重置身份密钥（修改已有密钥）
3. 退出
============================================================
请输入操作编号（1/2/3）：
```

- **操作 1：生成身份密钥（首次使用）** 输入编号 `1`。程序会自动读取 `input` 目录下的 Excel 文件，过滤姓名为空的无效行，为所有有效姓名生成唯一身份密钥。完成后结果自动保存到 `output` 目录。
- **操作 2：重置身份密钥** 输入编号 `2`，按提示选择重置范围：
  - 输入 `1`：一键重置所有姓名的身份密钥。
  - 输入 `2`：输入需要重置的姓名，多个姓名用英文逗号分隔（示例：`张三,李四,王五`）。 按提示选择是否保留历史密钥（输入 `y`/`n`，默认保留）。重置结果将覆盖保存到 `output` 目录。
- **操作 3：退出程序** 输入编号 `3`，程序安全退出。

### 5. 查看结果

- **结果文件**：生成或重置后的密钥文件保存在项目根目录的 `output` 文件夹中。
- **日志文件**：运行日志保存在项目根目录的 `logs` 文件夹中。遇到问题时可查看日志排查原因。

## 七、常见问题排查

### Q1：运行报错 `NameError: name 'Path' is not defined`

> **解决方案**：打开 `key_generator.py` 文件，在文件最顶部的导入区域（`import` 区），添加一行代码：`from pathlib import Path`。

### Q2：运行提示 “未找到 Excel 文件”

> **解决方案**：
>
> 1. 确认你的 Excel 文件已经正确放入了项目根目录的 `input` 文件夹中。
> 2. 确认 `config.py` 中的 `INPUT_EXCEL_FILENAME` 的值与你的实际 Excel 文件名**完全一致**（包含后缀名）。
> 3. 避免文件名和路径包含中文、空格、特殊符号，建议使用纯英文和数字命名。

### Q3：运行提示 “未找到姓名列”

> **解决方案**：打开 `config.py` 文件，修改 `NAME_COLUMN` 的值，使其与你 Excel 中姓名列的表头名称完全一致（注意区分大小写和空格）。

### Q4：重置密钥时提示 “未找到已生成的密钥文件”

> **解决方案**：请先选择【操作 1】完成首次密钥生成。只有在 `output` 目录下生成了结果文件后，才能执行重置操作。

### Q5：生成的 Excel 文件打开显示乱码

> **解决方案**：使用 WPS 或 Office 打开 Excel 时，选择以 `UTF-8` 编码格式打开；或者重新运行程序生成结果（程序默认使用 UTF-8 编码输出）。

## 八、注意事项

- **数据备份**：运行程序前，强烈建议备份你的原始 Excel 文件，以免操作失误导致数据丢失。
- **密钥安全**：本工具生成的密钥适用于普通身份标识场景，**请勿**直接用于金融交易、高级加密等高安全级别场景。
- **日志清理**：日志文件会自动分割。如需彻底清理日志，可直接进入 `logs` 目录删除 `.log` 结尾的文件。
- **扩展开发**：核心功能已进行模块化封装，具备一定 Python 基础的开发者可基于现有函数扩展批量导入、密钥有效性校验、批量导出等高级功能。
